# -superstore-sales-analysis
 Retail sales data analysis using Python, pandas, matplotlib and seaborn 


## Overview
Analysis of 9,994 retail orders to identify revenue trends,
product performance, and profitability drivers.

## Key Findings
- Technology drives 37% of total revenue
- Discounts above 20% consistently produce negative profit
- West region outperforms all other regions
- Q4 is the strongest quarter every year

## Tools Used
Python, pandas, numpy, matplotlib, seaborn, plotly
